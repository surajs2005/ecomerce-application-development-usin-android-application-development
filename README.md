# E-commerce Android App

An Android application for browsing products, adding to cart, and managing orders with smooth Material Design. Features user authentication, product categories, and local data storage using Room DB.

## Features
- User Authentication (Login/Signup)  
- Browse products by category  
- Add to cart and manage orders  
- Smooth Material Design UI  
- Local storage with Room DB  
- API integration with Retrofit  

## Tech Stack
- **Language:** Kotlin / Java  
- **Architecture:** MVVM  
- **Database:** Room  
- **Networking:** Retrofit / Volley  
- **UI:** Material Design, RecyclerView, ViewBinding
